## 样式与效果

- `style.css`：配色集中在文件顶部 `:root` 变量，红金/宣纸色一键换
- `script.js`：烟花自动燃放频率（`1100` 毫秒）、颜色数组 `COLORS` 可调
- 手机端已适配；开启系统「减少动态效果」时会自动关掉烟花动画

## 部署上线（免费）

- **GitHub Pages**：把本文件夹推到 GitHub 仓库 → Settings → Pages → 选 main 分支根目录，几分钟后得到 `https://用户名.github.io/仓库名/` 链接，微信可直接打开
- **Vercel**：注册后直接把这个文件夹拖进新建项目即可，自动生成 `https://xxx.vercel.app`
